# Helix 1.0 scope

This is the canonical product and packaging contract for the 1.0 release. It supersedes historical plans, proposed ADRs, and package version numbers. A release is ready only after the [release checklist](checklist.md) and [final evidence gate](../final-release-readiness.md) pass.

## Shipped surfaces

- **Mail, Drive, Chat, Assistant, and Admin** for one organization with 5–50 trusted users on the `business` security tier.
- Invite-only access. Public self-service signup and public multi-tenant SaaS are outside the release.
- Mail uses a supported managed outbound email provider, the web UI, and supported APIs.
- Drive provides upload, storage, folders, versions, sharing, download, WebDAV, and
  an [S3-compatible API](../drive-s3-api.md) (`/v1/s3`, SigV4 access keys) for the
  AWS CLI, rclone, and S3 SDKs. Editors, file viewers, and converters are outside the product.
- Chat uses TLS, organization and room authorization, retention controls, and
  deployment-attested encrypted storage. Chat is **not end-to-end encrypted**;
  authorized server administrators can technically access stored messages.
- Authorized agent reads may execute immediately. Agent writes require authenticated human confirmation by default unless an audited automation policy bounds the action, resource, target, time window, and rate.

## Production packaging

- `HELIX_MODE=single-tenant`
- `HELIX_WORKSPACE_PROFILE=mvp`
- `HELIX_SECURITY_TIER=business`
- `HELIX_APPS=mail,drive,chat,assistant` (exact; Admin is a control surface, not an app ID)
- `VITE_HELIX_MVP_ONLY=true`
- Calendar and Meet are dormant behind the `full` profile and are outside 1.0. Enabling them requires separate deployment and release evidence.
- `docker-compose.meet.yml` is the operator's opt-in to that profile on a single host, with a bundled Jitsi. It is never applied by default and is not covered by the 1.0 release evidence.
- Passwords is an optional administrator-enabled native personal KeePass vault. Browser-only encryption and human-session storage isolate it from agents, Drive, and search. The first slice supports logins, secure notes, encrypted export and previous-revision recovery; sharing, imports and external-client synchronization remain outside this slice. Existing Vaultwarden installations remain available through a legacy link until explicitly migrated.

## Explicit non-claims

- No native document editing, file viewers, converters, or sibling editor repository dependency.
- No installable third-party plugin runtime in 1.0; outbound webhook formats are built into the workspace.
- Helix does not operate direct-to-MX outbound mail. The pilot does not include a Helix-hosted IMAP server.
- No unattended agents with unrestricted write access, certification claims, contractual SLA, or multi-region active-active availability.
- Untrusted Business-tier uploads remain unavailable until integrity checks and a real malware scanner return a clean verdict. Scanner failures remain quarantined.
- Engineering objectives are 99.5% monthly availability, RPO of no more than 24 hours, and RTO of no more than 4 hours; these are not a contractual SLA.
