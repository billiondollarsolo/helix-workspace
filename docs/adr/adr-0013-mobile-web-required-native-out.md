# ADR-0013: Mobile web required; native apps out of v1

- **Status:** Proposed (2026-08-02) — owner approval pending for implementation authorization
- **Plan task:** G0.7
- **Date:** 2026-08-02

## Context

Shell mobile layout and safe-area work is in UX.12.

## Decision

Responsive **mobile web** is in scope for v1. Native mobile applications are **out of scope** for v1.

## Consequences

Prioritize Playwright 390×844 and responsive CSS. Do not staff native app programs under this plan.

## Reversal

Native apps require a separate product plan.
